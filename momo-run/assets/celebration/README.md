# 모모런 — 신기록 축하 이미지 자리

신기록 결과 카드에 띄울 축하 이미지를 여기에 넣으면 코드 수정 없이 자동으로 나옵니다.

- 파일 이름: `record.webp` (정확히 이 이름)
- 권장 크기: 800 × 800 (정사각형), 배경 투명 PNG/WebP도 좋습니다
- 카드 안에서 폭 최대 250px(폰 기준)로 줄어들어 표시됩니다
- 넣은 뒤에는 파일 버전을 올려 주세요 — `game.js`의 `CELEBRATE_SRC`(`assets/celebration/record.webp?v=1`) 숫자를 하나 올리면 폰 캐시에 옛 파일이 남지 않습니다
- 파일이 없으면 아무것도 표시되지 않습니다(오류 없음)
